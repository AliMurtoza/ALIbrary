# ALIbrary Project Plan

## Overview

ALIbrary is a modern, scalable Library Management System designed to streamline book circulation, member management, and branch operations through a clean and maintainable architecture.

The project follows Clean Architecture principles with a layered backend, a React frontend, and PostgreSQL as the primary database.

---

## Objectives

- Build a maintainable Library Management System
- Follow modern software engineering practices
- Deliver a secure and scalable REST API
- Provide a responsive and intuitive user experience

---

## Tech Stack

### Backend

- ASP.NET Core 8 Web API
- Entity Framework Core
- PostgreSQL

### Frontend

- React
- TypeScript
- Vite

### Authentication

- JWT Bearer Authentication

## Architecture
